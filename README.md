# 🔥 FIRE Assessment — UniRP by Bloomfield Innovations

**Free Intense Research Evaluation** — a structured diagnostic tool to assess a university's digital maturity, automation readiness, and ROI potential before ERP implementation.

## Overview

FIRE is a consulting-led assessment framework developed by [Bloomfield Innovations](https://bloomfieldinnovations.in) as part of the UniRP University Resource Planning platform. It shifts the sales approach from product-driven to value-driven by giving institutions a data-backed transformation roadmap before any technology investment.

## Features

- **5-pillar assessment** — Functional, Information, Automation, Economic, Strategic
- **25 questions** across all pillars with automatic FIRE Index calculation (0–100)
- **Maturity level infographic** — visual positioning across 5 levels from Critical Risk to Smart Digital University
- **ROI Calculator** — year-by-year projection based on institution size and benchmarks
